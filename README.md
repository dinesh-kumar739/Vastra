# Vastra 👕🛍️

Vastra is a modern full-stack e-commerce web application focused on clothing retail. 
Built with passion by Dinesh Kushwaha — developer & competitive programmer.

## Features
- 🛒 Add to Cart & Order Management
- 🔐 User Authentication (JWT + Google Login)
- 👨‍💼 Admin Panel for Product Management
- ☁️ Cloudinary Image Upload
- 📦 Filter by Category & Sub-Category
- 💳 Cash on Delivery Support

## Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Auth:** JWT, bcrypt, Google OAuth
- **Deployment:** Render (Backend), Vercel (Frontend)
